### 🚀 Featured Projects

**[AI Landscape Tracker](https://github.com/prasannareddy2192/ai-landscape-tracker)**
An end-to-end AI data pipeline that crawls and enriches 500+ AI models and research papers (Hugging Face, arXiv) using a local LLM, with hybrid keyword-semantic search via PostgreSQL/pgvector and a FastAPI backend, containerized with Docker.

**[GitHub Intelligence MCP Server](https://github.com/prasannareddy2192/github-intelligence-mcp)**
A Model Context Protocol (MCP) server exposing GitHub API tools, including LLM-powered README summarization, plus a custom MCP client running its own agent loop — integrated with Claude Desktop for real-time AI-to-tool orchestration.

**[Text-to-SQL Analytics Console](https://github.com/prasannareddy2192/sql-assistant)**
A FastAPI application that converts natural language into SQL queries using an LLM, with self-healing retry logic that automatically detects and corrects failed queries, and real-time data visualizations.
